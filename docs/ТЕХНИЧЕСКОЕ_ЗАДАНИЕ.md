# Техническое Задание

## Цель

Сделать приватный local-first мессенджер на Flutter с E2E-шифрованием, WebRTC/P2P сообщениями и звонками, а также PocketBase signaling.

## Функции

- Локальная регистрация без телефона и email.
- Генерация UUID и X25519 keypair на устройстве.
- Contact bundle для обмена public key.
- Список контактов из локальной БД.
- 1:1 чаты с E2E-шифрованием.
- Локальная история сообщений.
- Локальные encrypted attachments.
- WebRTC audio/video calls.
- WebRTC DataChannel для прямой доставки сообщений.
- PocketBase signaling для offer/answer/candidate/hangup.

## Нефункциональные требования

- Контакты и история не уходят во внешний history backend.
- Приватный ключ не экспортируется.
- Plaintext не логируется.
- Приложение должно запускаться без сети, кроме функций, которым нужен WebRTC/PocketBase.
- `POCKETBASE_URL` обязателен для signaling.

## Приемка

- `client/lib` не содержит cloud history/contact service.
- `client/pubspec.yaml` не содержит зависимости старого cloud backend.
- Контакт можно добавить через contact bundle.
- Сообщение сохраняется локально в encrypted DB.
- Звонок между двумя устройствами использует PocketBase signaling.
- Flutter analyze/tests должны быть пройдены в окружении с Flutter SDK.
