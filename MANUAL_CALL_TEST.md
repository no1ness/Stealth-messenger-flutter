## Ручное тестирование звонка

### Вариант 1: Между телефоном и эмулятором

1. **Запустите эмулятор**:
   ```bash
   emulator -avd <имя_AVD>
   ```

2. **Запустите приложение на эмуляторе**:
   ```bash
   cd client
   flutter run -d emulator-5554
   ```

3. **На телефоне**:
   - Откройте приложение
   - Перейдите в Contacts
   - Добавьте эмулятор в контакты (скопируйте User ID с эмулятора)

4. **На эмуляторе**:
   - Перейдите в Contacts
   - Добавьте телефон в контакты (скопируйте User ID с телефона)

5. **Инициируйте звонок**:
   - На эмуляторе: нажмите кнопку "Start call" на карточке контакта телефона
   - На телефоне: примите входящий звонок кнопкой "Answer"

6. **Проверьте**:
   - Статус звонка должен быть "Connected"
   - Аудио должно передаваться (говорите в микрофон одного устройства, слушайте на другом)

### Вариант 2: Между двумя телефонами

Если у вас есть два физических устройства:

1. Установите приложение на оба устройства
2. Зарегистрируйте пользователей на обоих
3. Добавьте контакты друг другу
4. Совершите звонок

### Вариант 3: Автоматизированный тест (когда эмулятор работает)

```bash
cd pw-test

# Убедитесь что Appium сервер запущен
appium

# В другом терминале запустите тест
node appium-simple-call-test.mjs
```

## Проверка WebRTC соединения

После установления звонка проверьте:

1. **Статус соединения**: должен быть "Connected" или "Negotiating"
2. **Аудио**: говорите в микрофон - звук должен передаваться
3. **Видео** (если включено): изображение должно передаваться
4. **Стабильность**: соединение не должно прерываться

## Известные проблемы

1. **Flutter CanvasKit**: UI рендерится на canvas, поэтому Appium не всегда может найти элементы
2. **User ID не виден в page source**: Flutter не экспонирует текст в XML для Appium
3. **Эмулятор может отключаться**: при длительной работе или нехватке ресурсов

## Полезные команды

```bash
# Проверить подключенные устройства
adb devices

# Установить APK
adb -s <device_id> install -r client/build/app/outputs/flutter-apk/app-debug.apk

# Запустить приложение
adb -s <device_id> shell am start -n com.example.turbo/.MainActivity

# Остановить приложение
adb -s <device_id> shell am force-stop com.example.turbo

# Очистить данные приложения
adb -s <device_id> shell pm clear com.example.turbo
```
