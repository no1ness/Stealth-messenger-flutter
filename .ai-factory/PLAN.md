# План реализации: P2P-мессенджинг, фикс звонков и гибридный оффлайн-режим

## Описание
Переработка приложения для обеспечения максимальной скорости и приватности. Основная концепция: **Direct P2P First**. Сообщения и звонки идут напрямую между устройствами через WebRTC. Supabase используется как вспомогательный сервер для сигналинга, обхода NAT и как **хранилище резервных копий (History Cloud)**, куда данные синхронизируются в фоновом режиме по таймеру или в периоды простоя.

## Задачи (Tasks)

### Фаза 1: Исправление WebRTC и Базовых функций
1. **Анализ и фикс WebRTC (Audio/Video):**
   - Устранить ошибки установки соединения в `webrtc_support.dart`.
   - Проверить корректность ICE-кандидатов и использование TURN.
2. **Фикс отправки файлов:**
   - Исправить загрузку/скачивание в Supabase Storage с учетом E2E шифрования.

### Фаза 2: P2P Мессенджинг (WebRTC Data Channels)
3. **Реализация RTCDataChannel:**
   - Настроить канал данных внутри WebRTC сессии для мгновенного обмена сообщениями напрямую между устройствами.
4. **Маршрутизация сообщений (Hybrid Delivery):**
   - Реализовать логику: если P2P соединение установлено — отправлять сообщение через него (мгновенно). 
   - Если P2P недоступно — использовать Supabase Realtime как резервный канал.

### Фаза 3: Локальное хранилище и Фоновая синхронизация
5. **Local-first БД:**
   - Все сообщения (полученные по P2P или из Supabase) сохраняются первично в локальную базу данных (Isar или sqflite).
6. **Background Sync Service (История в облаке):**
   - Реализовать механизм "ленивой" синхронизации: по таймеру или при простое приложения локальные сообщения помечаются как `synced` и копируются в Supabase.
   - Это обеспечит восстановление истории при утере устройства.
7. **Дедупликация:**
   - Механизм проверки ID сообщений, чтобы избежать дублей при получении одного и того же сообщения разными путями.

### Фаза 4: Работа без VPN и Оффлайн-режим
8. **Обход блокировок:**
   - Настройка кастомных Proxy/Relay для сигналинга (Supabase), чтобы приложение работало без сторонних VPN сервисов.
9. **UI Настройки:**
   - Тумблер "Только P2P", "Оффлайн режим", "Частота синхронизации с облаком".
