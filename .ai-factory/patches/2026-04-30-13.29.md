# Patch: WebRTC Call Screen Test Stability

## Summary

Fixed a widget-test startup regression after moving call signaling to PocketBase. The call screen now remains constructible in tests even when `.env` is not loaded.

## Lessons

- Widget constructors should not require global env initialization.
- Runtime bootstrap belongs in `main.dart`; UI state creation should stay test-safe.
- Keep signaling dependencies isolated behind dedicated services.
