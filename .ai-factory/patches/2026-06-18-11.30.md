# Rename bypass label to whitelist in settings

**Date:** 2026-06-18 11:30
**Files:** client/lib/ui/screens/settings_screen.dart
**Severity:** low

## Problem

Settings screen showed "Обход цензуры" (censorship bypass) which is
politically loaded terminology. Requested to rename to "Белые списки"
(whitelists).

## Root Cause

The bypass feature was labelled with confrontational terminology
that draws unwanted attention. Whitelist framing is neutral and
technically accurate — the feature filters access via allowlists.

## Solution

- Changed `title: Text('Обход цензуры')` → `Text('Белые списки')`
- Updated subtitle from `'Прокси активен — трафик через sing-box'` →
  `'Прокси активен'` and `'Прямое подключение'` → `'Выключено'`

## Prevention

Review UI labels for politically loaded terms before merging.
Prefer neutral technical descriptions.
