# Fix file/voice/image display in chat — hide raw URL text

**Date:** 2026-06-20 21:15
**Files:** conversation_panel.dart, glass_chat_bubble.dart
**Severity:** medium

## Problem

When sending files, voice recordings, or images, the raw URL/blob was displayed as text in the chat bubble alongside the attachment widget. For example, an encrypted file URL like `enc://a1b2c3...` would appear as readable text in the bubble.

## Root Cause

The `GlassChatBubble` widget always displayed `message['message']` as text, even when an `attachmentWidget` was present. The `conversation_panel.dart` always passed the raw URL as the message text.

## Solution

- In `conversation_panel.dart`: when `attachmentWidget` is not null, set `displayText` to empty (or just the edited marker)
- In `glass_chat_bubble.dart`: only display the `Text` widget when `message.isNotEmpty` and there's no attachment, or when there IS an attachment and message has content

## Prevention

- When adding attachment support, always check if the message type is an attachment before displaying raw text
- Use `attachmentWidget == null` guard before showing text content
