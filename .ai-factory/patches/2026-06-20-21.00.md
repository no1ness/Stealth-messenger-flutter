# Remove dead parameters and hardcoded colors from Telegram redesign

**Date:** 2026-06-20 21:00
**Files:** telegram_sidebar.dart, telegram_header.dart, main_tabs.dart, chats_screen.dart
**Severity:** low

## Problem

Review found 6 issues in the Telegram redesign commit:
1. Dead `onCreateGroup` parameter in TelegramSidebar (accepted but never used)
2. Dead `isOnline` parameter in TelegramHeader (accepted but never used)
3. Hardcoded colors in main_tabs.dart instead of using AppColors design tokens
4. Dead `label` parameter in `_buildNavIconButton` (accepted but never used)
5. Silent exception swallowing in `_loadContacts()` catch block
6. Dead `showStats` parameter in `_buildChatListPanel` (always false after redesign)

## Root Cause

Parameters were added during initial implementation planning but never wired up. Colors were hardcoded for quick prototyping instead of using the design system. Error handling was minimal during initial scaffolding.

## Solution

- Removed dead parameters from widget constructors
- Replaced hardcoded `Color(0x...)` with `AppColors.systemBlue`, `AppColors.textSecondary`, `AppColors.dividerSubtle`
- Added `Logger.warn()` to catch block for debugging
- Removed dead `showStats` parameter and unused `create_group_sheet.dart` import

## Prevention

- During code review, check all constructor parameters are actually used
- Use design system tokens (AppColors) from the start, not hardcoded colors
- Always add logging to catch blocks even during scaffolding
